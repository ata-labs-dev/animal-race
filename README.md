# 🎲Animal Race

A multiplayer dice game developed using **Python** and **Pygame**, where players roll the dice, move their characters, and compete to reach the finish line.

### Features
- 2, 3, and 4-player modes
- Dice-based movement
- Turn-based gameplay
- Automatic winner detection

### Gameplay
Players take turns rolling the dice and moving across the board. The first player to reach the finish line wins.
